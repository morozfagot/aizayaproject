## Известные проблемы и решения

### Проблема 1: Vector Dimension Mismatch
**Симптомы:** Индексация показывает 100000+ блоков, но WS возвращает 0 файлов.
**Причина:** Хардкод `?? 1536` при реальной размерности 4096.
**Решение:** Убери хардкод. Используй размерность из конфигурации модели.

### Проблема 2: Empty modelId в OpenRouterEmbedder
**Симптомы:** `embeddings:validation.invalidResponse`.
**Причина:** `validateConfiguration()` отправляет запрос с пустым `modelId`.
**Решение:** Добавь раннюю проверку `if (!this.defaultModelId) return { valid: false, error: "modelIdRequired" }`.

### Проблема 3: WS контекст не попадает в модель
**Симптомы:** `wsResultCount: 5`, но `enrichedContext: false`.
**Причина:** WS находит фрагменты, но они не инжектятся в контекст модели.
**Решение:** Проверь код в Task.ts, который передаёт WS результаты в step 4.

### Проблема 4: Fallback query застрял
**Симптомы:** WS использует одно и то же старое сообщение.
**Причина:** Fallback берёт устаревший контекст из истории.
**Решение:** Исправь формирование fallback query — используй актуальное сообщение.

### Проблема 5: Кракозябры в исходниках
**Симптомы:** TypeScript компиляция падает с ошибками парсинга.
**Причина:** Русский текст в файлах сохранён в CP1251.
**Решение:** Конвертируй файлы в UTF-8 или удали русский текст.

### Проблема 6: VSIX содержит старый код
**Симптомы:** После пересборки VSIX содержит старый код.
**Причина:** Кеш turbo не очищен.
**Решение:** Всегда очищай кеш turbo перед сборкой (шаг 3.1).

### Проблема 7: Turbo build зависает
**Симптомы:** `turbo build` зависает на шаге.
**Решение:** Очисти кеш turbo: `rimraf .turbo`

## Источники опыта

Этот скилл основан на реальном опыте сборки форка Roo Code (morozcode) с:
- Qdrant векторной БД для RAG
- OpenRouter API для embeddings
- Динамическим выбором LLM моделей
- Workspace context enrichment

**Ключевые уроки:**
1. Никогда не хардкодируй размерность векторов
2. Всегда нормализуй workspacePath
3. Проверяй modelId перед API-запросами
4. Не удаляй коллекции при несовпадении размерности
5. Используй UTF-8 для всех исходников
6. Логируй workspacePath для диагностики
7. **Всегда очищай кеш turbo перед сборкой**
8. **Всегда проверяй TypeScript компиляцию ДО сборки**
9. **Никогда не перезаписывай старую версию — всегда инкрементируй**
