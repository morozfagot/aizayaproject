## Структура AiZayaProject

```
AiZayaProject/
├── .git/                    # Git репозиторий ЗДЕСЬ
├── morozcode/               # VS Code расширение (НЕ отдельный репозиторий)
│   ├── src/
│   ├── assets/
│   ├── package.json
│   └── ...
├── docs/                    # Документация
├── README.md
├── .gitignore
└── ...
```

## Важно

- `morozcode/` — это НЕ отдельный репозиторий, а поддиректория `AiZayaProject/`
- Все git-команды выполнять из `AiZayaProject/` (корень репозитория)
- При коммите изменений morozcode использовать пути относительно `AiZayaProject/`
